# AI 睡眠与梦境系统

给 AI 伴侣加一套「像人一样睡觉」的功能：他会困、会自己决定睡多久、睡着时会攒下 TA 发来的话、睡醒后像平常一样来找 TA，睡着时还会做梦，梦写下来存进一个梦境页。

它不是按钟点定时的「到点休息」，而是**数值驱动**的：困意在涨，情绪在压或松，线过了才睡。你看到的只是结果：聊天里他说「我去睡一会儿」，过一阵他醒来发一条消息；翻到梦境页，有一篇他写的梦。

> 文中的「他」指 AI 伴侣，「TA」指他的爱人（也就是你）。示例里的对话、梦、数字都只是例子，换成你们自己的。

## 它能做什么

- **困意与压力**：困意随时间自己涨（夜里涨得快、午后有小低谷）；安心、心软让他更困，焦虑、兴奋、想 TA 想得狠让他睡不着。
- **白天小睡 / 夜里分段睡**：他自己在回复里写 `⟪睡 3小时⟫` 决定睡多久，没写就随机一段；到点醒来，再决定要不要继续睡。
- **睡着时世界在继续**：TA 发来的话按概率吵醒他，没吵醒就攒着，醒来合在一起自然地回；电话和「醒醒」必醒。
- **醒来像平常一样**：不带「刚醒」的固定口气，只是知道自己刚睡过、刚做过梦，可以继续去做别的事；白天小睡醒来一定会发一条。
- **做梦**：素材来自今天情绪最重的事、昨天没做完的、心里挂着的、很远的旧事；梦会变形而不是复述，写完只留一缕「梦痕」；噩梦、重梦会把他惊醒。
- **聊天里的小标记**：每次去睡，聊天里落一条「1 step」；TA 发话没吵醒他时，那条话下面显示「他睡着了」。

## 怎么读这份教程

| 想怎么用 | 打开哪个 |
|---|---|
| 在浏览器里舒服地看（目录、深浅色、手机能看、代码块一键复制） | 下载仓库后，双击 [`docs/index.html`](docs/index.html) |
| 直接丢给你家的 AI（Claude Code 之类）让它照着做 | 把 [`教程.md`](教程.md) 整份发给它；网页版顶上也有「复制全文」按钮 |

教程分两部分：

- **上半（第 1–9 章）讲原理**：给人读的。一张总图、困意与压力、什么时候睡、睡着时发生什么、醒来、做梦、页面上看到的、一晚的例子、想调什么改哪里。
- **下半（第 10–19 章）是搭建手册**：给 AI 照着实现的。文件、状态文件、记号与接口、引擎心跳、提示词骨架、聊天侧接入、配置表、验收清单、踩过的坑、做大做小。

## 给读这份文档的 AI

文档里所有的数字（困意涨多快、几点算夜里、小睡多长、被吵醒和做梦的概率、提示词的措辞……）都只是参考值，**可以按你们自己的喜好和想法随意调配、增删**。某一章用不上就整段不做。结构和思路可以照搬，具体的数据以你们喜欢的为准。
